    @Override
    public void onInitializeClient() {
        // 1. Рендерер сущности
        registerIceShardRenderer();
        
        // 2. HUD маны
        HudElementRegistry.attachElementBefore(
            VanillaHudElements.CHAT,
            Identifier.of("manaborn", "mana_display"),
            ManaHudOverlay::render
        );
        
        // 3. HUD заклинания
        HudElementRegistry.attachElementBefore(
            VanillaHudElements.CHAT,
            Identifier.of("manaborn", "spell_display"),
            SpellHudOverlay::render
        );
        
        // 4. Прием пакетов
        ClientPlayNetworking.registerGlobalReceiver(
            ManaSyncS2CPacket.ID, 
            (payload, context) -> {
                context.client().execute(() -> 
                    ClientManaState.set(payload.mana(), payload.maxMana())
                );
            }
        );
        
        // 5. Клиентские тики
        ClientTickEvents.END_CLIENT_TICK.register(client -> {
            if (client.player != null) {
                ClientManaState.clientTick();
            }
        });
    }

12. ManaHudOverlay.java - ОТОБРАЖЕНИЕ МАНЫ
================================================================================

Путь: src/client/java/com/manaborn/client/ManaHudOverlay.java

    public static void render(DrawContext context, RenderTickCounter ticker) {
        MinecraftClient client = MinecraftClient.getInstance();
        if (client == null || client.player == null || client.options.hudHidden) {
            return;
        }
        
        int currentMana = ClientManaState.getMana();
        int screenWidth = context.getScaledWindowWidth();
        int screenHeight = context.getScaledWindowHeight();
        
        int startX = screenWidth - 110;
        int startY = screenHeight - 50;
        
        // Рисуем 10 пузырьков
        for (int i = 0; i < 10; i++) {
            int x = startX + (i * 10);
            int y = startY;
            
            boolean filled = (i * 10) < currentMana;
            int fillColor = filled ? 0xFF4DA3FF : 0xFF000000;
            int borderColor = 0xFF1F1F1F;
            
            context.fill(x, y, x + 9, y + 9, borderColor);
            context.fill(x + 1, y + 1, x + 8, y + 8, fillColor);
        }
    }

РИСОВАНИЕ:
    context.fill(x1, y1, x2, y2, color);

Прямоугольник от (x1, y1) до (x2, y2)

ЦВЕТА (ARGB):
    0xAARRGGBB
    AA = прозрачность (FF = непрозрачный)
    RR = красный
    GG = зеленый
    BB = синий

Примеры:
    0xFF000000 = черный
    0xFFFFFFFF = белый
    0xFF4DA3FF = голубой
    0x80FFFFFF = белый полупрозрачный

ЛОГИКА ПУЗЫРЬКОВ:
- 10 пузырьков
- Каждый = 10 маны
- 100 маны = все заполнены
- 50 маны = 5 заполнены

    public static void render(DrawContext ctx, RenderTickCounter ticker) {
        MinecraftClient client = MinecraftClient.getInstance();
        if (client == null || client.player == null) return;
        
        // Проверяем, держит ли игрок посох
        ItemStack mainHand = client.player.getMainHandStack();
        ItemStack offHand = client.player.getOffHandStack();
        
        ItemStack staff = null;
        if (mainHand.getItem() instanceof MagicStaffItem) {
            staff = mainHand;
        } else if (offHand.getItem() instanceof MagicStaffItem) {
            staff = offHand;
        }
        
        if (staff == null) return;
        
        SpellType spell = SpellManager.getSelectedSpell(staff);
        
        int x = screenWidth - 120;
        int y = 20;
        
        // Фон
        ctx.fill(x - 2, y - 2, x + 110, y + 30, 0x80000000);
        
        // Текст
        Text spellText = Text.literal(spell.getDisplayName());
        ctx.drawText(client.textRenderer, spellText, x + 5, y + 5, 0xFFFFFFFF, false);
        
        Text costText = Text.literal("Стоимость: " + spell.getManaCost() + " маны");
        ctx.drawText(client.textRenderer, costText, x + 5, y + 15, 0xFFAAAAAA, false);
    }

14. ClientManaState.java - СОСТОЯНИЕ НА КЛИЕНТЕ
================================================================================

Путь: src/client/java/com/manaborn/client/state/ClientManaState.java

    public class ClientManaState {
        private static int mana = 100;
        private static int maxMana = 100;
        private static long lastUpdateTime = 0;
        
        public static void set(int newMana, int newMaxMana) {
            mana = newMana;
            maxMana = newMaxMana;
            lastUpdateTime = System.currentTimeMillis();
        }
        
        public static void clientTick() {
            if (mana >= maxMana) return;
            
            long now = System.currentTimeMillis();
            if (now - lastUpdateTime > 500) {  // 0.5 сек
                mana = Math.min(mana + 1, maxMana);
                lastUpdateTime = now;
            }
        }
        
        public static int getMana() { return mana; }
        public static int getMaxMana() { return maxMana; }
    }

ЗАЧЕМ КЛИЕНТСКАЯ РЕГЕНЕРАЦИЯ?
- Сервер отправляет обновления не каждый тик
- Клиент делает плавную интерполяцию
- Визуально приятнее

ВАЖНО: Это только для визуала!
Истинная мана - на сервере.

15. ПОЛНЫЙ ЦИКЛ РАБОТЫ МАНЫ
================================================================================

ВХОД ИГРОКА:
1. ServerPlayConnectionEvents.JOIN
2. ManaManager.ensureInitialized(player)
3. ManaManager.sendSync(player)
4. Пакет → Клиент
5. ClientManaState.set(100, 100)
6. HUD обновляется

ИСПОЛЬЗОВАНИЕ ПОСОХА:
1. Игрок нажимает ПКМ
2. MagicStaffItem.use()
3. SpellManager.castSpell()
4. ManaManager.tryConsume(player, 20)
5. Мана: 100 → 80
6. ManaManager.sendSync(player)
7. Пакет → Клиент
8. ClientManaState.set(80, 100)
9. HUD обновляется

РЕГЕНЕРАЦИЯ:
1. Каждый тик: ServerTickEvents
2. ManaManager.onServerTick(players)
3. Проверка: прошло 2 сек?
4. Да → счетчик++
5. Каждые 5 тиков: мана++
6. ManaManager.sendSync(player)
7. Пакет → Клиент
8. HUD обновляется

16. СЕТЕВОЕ ВЗАИМОДЕЙСТВИЕ
================================================================================

ЗАЧЕМ ПАКЕТЫ?
Клиент и сервер - разные программы
Нужно передавать данные

СОЗДАНИЕ ПАКЕТА:
1. Определить структуру (record)
2. Создать ID
3. Создать CODEC
4. Зарегистрировать

РЕГИСТРАЦИЯ:
    // Сервер
    PayloadTypeRegistry.playS2C().register(ID, CODEC);

ОТПРАВКА:
    // С сервера
    ServerPlayNetworking.send(player, new MyPacket(data));

ПРИЕМ:
    // На клиенте
    ClientPlayNetworking.registerGlobalReceiver(
        MyPacket.ID, 
        (payload, context) -> {
            context.client().execute(() -> {
                // Обработка
            });
        }
    );

ПОЧЕМУ context.client().execute()?
- Пакеты в сетевом потоке
- Нельзя менять игру из другого потока
- execute() = главный поток

17. ЧАСТЫЕ ВОПРОСЫ
================================================================================

Q: Код не работает на сервере?
A: Импортировали клиентский класс в main!

Q: Игра крашится при спавне сущности?
A: Нет рендерера в ManabornClient!

Q: Мана не синхронизируется?
A: Забыли ManaManager.sendSync(player)!

Q: Что такое UUID?
A: Уникальный ID игрока (не меняется)

Q: Что такое тик?
A: 1/20 секунды (20 тиков = 1 секунда)

Q: Как добавить новое заклинание?
A: 
1. Добавить в SpellType
2. Добавить case в SpellManager
3. Написать метод каста
4. Если нужна сущность - зарегистрировать

Q: Почему if (world.isClient())?
A: Метод вызывается на обеих сторонах
   Логику делаем только на сервере

Q: Что такое NBT?
A: Данные в предметах
   Сохраняются при перезаходе

Q: Зачем @SuppressWarnings("deprecation")?
A: EntityRendererRegistry deprecated
   Но это всё ещё рабочий способ для 1.21.10
