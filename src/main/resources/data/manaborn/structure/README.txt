📂 ПАПКА ДЛЯ NBT СТРУКТУР

Сюда нужно скопировать файл: magic_shrine.nbt

ОТКУДА ВЗЯТЬ:
После сохранения через Structure Block, файл будет здесь:
.minecraft/saves/<world_name>/generated/minecraft/structures/manaborn/magic_shrine.nbt

КОМАНДА ДЛЯ РУЧНОГО РАЗМЕЩЕНИЯ (тестирование):
/place structure manaborn:magic_shrine ~ ~ ~

Эта команда разместит структуру в текущей позиции игрока.
Полезно для проверки что NBT файл загружается правильно!
