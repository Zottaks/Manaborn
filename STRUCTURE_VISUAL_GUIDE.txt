БЕЛАЯ РАМКА ВОКРУГ ПОСТРОЙКИ:

После нажатия DETECT ты увидишь белую рамку:

    ┌───────────┐  ← Верх структуры
    │▓▓▓▓▓▓▓▓▓▓▓│
    │▓         ▓│
    │▓  ТВОЯ   ▓│
    │▓ БАШНЯ   ▓│
    │▓         ▓│
    │▓▓▓▓▓▓▓▓▓▓▓│
    └───────────┘
    ◉            ← Structure Block

Если рамка охватывает всю постройку - ВСЁ ПРАВИЛЬНО! ✅
Если нет - измени размеры вручную.

ЧАСТЫЕ ОШИБКИ:

❌ НЕПРАВИЛЬНО: Structure Block ВНУТРИ постройки
   ┌─────────────┐
   │  ▓ ▓ ▓ ▓ ▓  │
   │  ▓ ◉   ▓    │  ← Блок внутри!

   └─────────────┘
   Результат: Сохранится только часть!


✅ ПРАВИЛЬНО: Structure Block СНАРУЖИ, в углу
   ┌─────────────┐
   │  ▓ ▓ ▓ ▓ ▓  │
   │  ▓       ▓  │
   │  ▓ ▓ ▓ ▓ ▓  │
   └─────────────┘
   ◉              ← Блок снаружи!
   Результат: Сохранится всё! ✅


═══════════════════════════════════════════════════════════════

ВАЖНЫЕ МОМЕНТЫ:

1. Structure Block должен быть НА ЗЕМЛЕ (Y=0 относительно постройки)

2. Координаты блока = координаты ЛЕВОГО НИЖНЕГО угла структуры

3. Белая рамка показывает что будет сохранено

4. "Show air" = сохранит пустое пространство внутри

5. После SAVE файл появится в папке мира через 1-2 секунды


═══════════════════════════════════════════════════════════════

БЫСТРАЯ ПРОВЕРКА:

После сохранения можешь разместить структуру командой:

/place structure manaborn:magic_shrine ~ ~ ~

Это разместит структуру прямо где ты стоишь.
Если всё ок - можно копировать NBT в мод!
