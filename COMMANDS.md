# 🎮 Команды Manaborn

## `/manaborn reset_spells [player]`

**Назначение:** Полный сброс всех изученных заклинаний и их уровней

**Требования:** Уровень OP 2 или выше

### Использование:

#### 1. Сбросить свои заклинания:
```
/manaborn reset_spells
```

**Результат:**
- Все изученные заклинания удаляются
- Все уровни заклинаний сбрасываются
- Сообщение: "§6Все твои заклинания и их уровни были сброшены!"

#### 2. Сбросить заклинания другого игрока:
```
/manaborn reset_spells Steve
```

**Результат:**
- Заклинания указанного игрока сбрасываются
- Игрок получает сообщение: "§6Все твои заклинания и их уровни были сброшены администратором!"
- Администратор получает подтверждение: "§aЗаклинания игрока Steve сброшены!"

---

## 🔍 Что делает команда:

### Сброс изученных заклинаний:
1. Очищает список изученных заклинаний (`LearnedSpellsManager.clearPlayer`)
2. Повторно инициализирует пустой список
3. Синхронизирует с клиентом

### Сброс уровней заклинаний:
1. Очищает все уровни заклинаний (`SpellLevelManager.clearPlayer`)
2. При следующем изучении заклинания оно будет уровня 1
3. Синхронизирует с клиентом

---

## 💡 Примеры использования:

### Сценарий 1: Тестирование прокачки
```
/manaborn reset_spells
# Теперь можно заново изучать заклинания и тестировать систему уровней
```

### Сценарий 2: Сброс прогресса игрока
```
/manaborn reset_spells PlayerName
# Полезно для администраторов при рестарте сезона
```

### Сценарий 3: Исправление багов
Если у игрока проблемы с заклинаниями:
```
/manaborn reset_spells PlayerName
# Очистка и повторное изучение решит большинство проблем
```

## ⚙️ Технические детали:

### Что НЕ сбрасывается:
- ❌ Мана игрока (остаётся как есть)
- ❌ Предметы в инвентаре
- ❌ Ресурсы (магическая пыль, эфир и т.д.)

### Что сбрасывается:
- ✅ Список изученных заклинаний
- ✅ Уровни ВСЕХ заклинаний (1-3)
- ✅ Выбранное заклинание на посохе (очищается)

### Синхронизация:
Команда автоматически отправляет пакеты синхронизации:
- `LearnedSpellsSyncS2CPacket` - обновление списка заклинаний
- `SpellLevelSyncS2CPacket` - обновление уровней

Клиент мгновенно получает обновления и GUI обновляется автоматически.

---

## 🛡️ Безопасность:

- Требуется уровень OP 2 (permission level 2)
- Команда не может быть выполнена обычными игроками
- Подтверждение для обеих сторон (администратор + игрок)
- Безопасна для использования в multiplayer
