📝 ЧТО ДЕЛАТЬ В ИГРЕ:

1. Поставь Structure Block в ЛЕВЫЙ НИЖНИЙ УГОЛ постройки

2. ПКМ по блоку → Настрой:
   ┌─────────────────────────────────────────┐
   │ Mode: SAVE                              │
   │ Structure Name: manaborn:magic_shrine   │
   │ ☑ Show air                              │
   │ ☑ Show bounding box                     │
   │ ☑ Include entities                      │
   └─────────────────────────────────────────┘

3. Нажми кнопку DETECT (авто размеры) ИЛИ укажи вручную:
   - Size X: _____
   - Size Y: _____
   - Size Z: _____

4. Нажми SAVE ✅

🎮 ТЕСТИРОВАНИЕ:

1. Скопируй NBT файл (см. выше)

2. Запусти:
   .\gradlew build
   .\gradlew runClient

3. Создай НОВЫЙ МИР (важно!)

4. Найди структуру:
   /locate structure manaborn:magic_shrine
