1. КЛИЕНТ И СЕРВЕР
================================================================================

Minecraft работает в ДВУХ РЕЖИМАХ:

СЕРВЕР:
- Хранит правду о мире
- Обрабатывает логику (урон, физика)
- Решает, что происходит

КЛИЕНТ:
- Показывает картинку
- Воспроизводит звуки
- Отображает HUD

ВАЖНО: Логика ТОЛЬКО на сервере!

Пример:
    if (world.isClient()) {
        return;  // На клиенте ничего не делаем
    }
    // Логика на сервере

СТРУКТУРА:
- src/main/java/  - работает везде
- src/client/java/ - только клиент

ПРАВИЛО: НЕ импортируйте клиент в main!

2. ManabornMod.java - ГЛАВНЫЙ ФАЙЛ
================================================================================

Путь: src/main/java/com/manaborn/ManabornMod.java

Вызывается при запуске игры.

ШАГ 1: Регистрация пакета
    PayloadTypeRegistry.playS2C().register(
        ManaSyncS2CPacket.ID, 
        ManaSyncS2CPacket.CODEC
    );

S2C = Server to Client

ШАГ 2: Регистрация сущности
    ICE_SHARD_ENTITY = Registry.register(
        Registries.ENTITY_TYPE,
        iceShardKey,
        EntityType.Builder.<IceShardEntity>create(...)
            .dimensions(0.5f, 0.5f)
            .build(iceShardKey)
    );

ШАГ 3: Регистрация предмета
    MAGIC_STAFF = Registry.register(
        Registries.ITEM, 
        staffKey, 
        new MagicStaffItem(...)
    );

ШАГ 4: Тики сервера
    ServerTickEvents.END_SERVER_TICK.register(server -> {
        ManaManager.onServerTick(...);
    });

Тик = 1/20 секунды
20 тиков = 1 секунда

ШАГ 5: Вход игрока
    ServerPlayConnectionEvents.JOIN.register(...) -> {
        ManaManager.ensureInitialized(player);
        ManaManager.sendSync(player);
    });

3. ManaManager.java - СИСТЕМА МАНЫ
================================================================================

Путь: src/main/java/com/manaborn/mana/ManaManager.java

КОНСТАНТЫ:
    MAX_MANA = 100
    REGEN_UNIT_PER_5S = 20  // 20 маны за 5 сек
    REGEN_DELAY_TICKS = 40  // 2 секунды

ХРАНИЛИЩА:
    Map<UUID, Integer> playerIdToMana
    Map<UUID, Long> lastSpendTick
    Map<UUID, Integer> regenTickCounter

UUID = уникальный ID игрока

ПОЛУЧЕНИЕ МАНЫ:
    public static int getMana(UUID playerId) {
        return playerIdToMana.getOrDefault(playerId, MAX_MANA);
    }

ТРАТА МАНЫ:
    public static boolean tryConsume(player, amount) {
        if (current >= amount) {
            setMana(id, current - amount);
            lastSpendTick.put(id, time);
            sendSync(player);
            return true;
        }
        return false;
    }

РЕГЕНЕРАЦИЯ:
    public static void onServerTick(players) {
        for (player : players) {
            if (мана полная) continue;
            if (прошло < 2 сек) continue;
            
            counter++;
            if (counter >= 5) {
                мана++;
                counter = 0;
                sendSync(player);
            }
        }
    }

Логика: каждые 5 тиков +1 мана = 4 маны/сек

4. ManaSyncS2CPacket.java - СЕТЕВОЙ ПАКЕТ
================================================================================

Путь: src/main/java/com/manaborn/network/ManaSyncS2CPacket.java

    public record ManaSyncS2CPacket(int mana, int maxMana) {
        public static final Id ID = ...;
        public static final PacketCodec CODEC = ...;
    }

record = короткая запись класса данных

PacketCodec = как упаковать в байты

Отправка:
    Сервер: new ManaSyncS2CPacket(75, 100)
    → CODEC превращает в байты
    → Клиент получает
    → CODEC превращает обратно
    → ClientManaState.set(75, 100)
