# ✨ Manaborn

**Manaborn** — магический мод для Minecraft, добавляющий систему маны и заклинаний.

## 📖 Описание

Manaborn добавляет в игру полноценную систему магии с маной, магическими посохами и различными заклинаниями. Игроки получают доступ к 100 единицам маны, которая автоматически восстанавливается со временем.

### ✨ Основные возможности

- **Система маны**: 100 единиц максимум с автоматической регенерацией
- **Магический посох**: универсальный инструмент для сотворения заклинаний
- **9 уникальных заклинаний**: от огненных шаров до защитных барьеров
- **Система изучения**: находите книги и изучайте заклинания через Алтарь Изучения
- **HUD интерфейс**: визуальное отображение маны, активного заклинания и кулдаунов
- **Система кулдаунов**: балансировка использования заклинаний
- **Магические предметы**: зелья маны, сосуды, магическая пыль
- **Мистические блоки**: магическая руда, конвертер маны, алтарь изучения

## 🎮 Геймплей

### Система маны

- **Максимум**: 100 единиц маны
- **Регенерация**: 20 маны за 5 секунд (1 мана каждые 5 тиков)
- **Задержка**: 2 секунды после использования заклинания перед началом регенерации
- **Отображение**: визуальные пузырьки в правом нижнем углу экрана

### Магический посох (Mana Wand)

Универсальный магический инструмент для сотворения заклинаний.

**Крафт:**
```
  🔮    (Осколок аметиста)
 🪵     (Палка)
🪵      (Палка)
```

**Ингредиенты:**
- 2x Палка (`minecraft:stick`)
- 1x Осколок аметиста (`minecraft:amethyst_shard`)

**Управление:**
- **ПКМ** — использовать активное заклинание
- **Shift + ПКМ** — переключить заклинание (только изученные)

**Особенности:**
- Кулдаун 5 секунд после использования
- Отображение активного заклинания в названии предмета
- Подробные подсказки (tooltip) с информацией о заклинаниях
- Требует изучения заклинаний через Алтарь Изучения

### 🧪 Магические предметы

#### Зелья маны (Mana Potion)
- **Эффект**: мгновенно восстанавливает 50 единиц маны
- **Крафт**: 
```
   💧      (Ведро воды)
 ✨🧪✨ (Магическая пыль + Бутылка)
```
- **Ингредиенты**: 1x Бутылка, 2x Магическая пыль, 1x Ведро воды

#### Магическая пыль (Magic Dust)
- **Использование**: компонент для крафта магических предметов
- **Получание**: добывается из магической руды (1-3 штуки)

#### Сосуды маны (Mana Vessel)
- **Функция**: хранение и перенос маны
- **Вместимость**: до 100 единиц маны
- **Крафт**:
```
   ✨      (Магическая пыль)
 🏺🏺🏺 (Стеклянные бутылки)
```
- **Ингредиенты**: 4x Стеклянная бутылка, 1x Магическая пыль
- **Использование**: можно пополнять и использовать для восстановления маны

### 🏺 Магические блоки

#### Магическая руда (Magic Ore)
- **Генерация**: находится в глубинах мира (ниже Y=16)
- **Добыча**: добывается железной киркой или лучше
- **Дроп**: магическая пыль (1-3 штуки)

#### Конвертер маны (Mana Converter)
- **Функция**: преобразует предметы в ману
- **Использование**: позволяет конвертировать редкие минералы в ману
- **Интерфейс**: специальный экран для конвертации

### Заклинания

#### 🔥 Огненный шар (Fireball)
- **Стоимость**: 20 маны
- **Эффект**: запускает огненный снаряд, поджигающий врагов
- **Звук**: звук использования огненного заряда

#### ❄️ Ледяной осколок (Ice Shard)
- **Стоимость**: 35 маны
- **Эффект**: запускает ледяной снаряд, замедляющий врагов
- **Дебафф**: Замедление III на 5 секунд
- **Звук**: звук выстрела снежного голема

#### 🔥 Стена огня (Fire Wall)
- **Стоимость**: 50 маны
- **Эффект**: создает стену из огня, наносящую урон врагам
- **Продолжительность**: 10 секунд

#### 🌡️ Внутренний жар (Inner Heat)
- **Стоимость**: 30 маны
- **Эффект**: дает сопротивление к огню и урону от холода
- **Продолжительность**: 30 секунд

#### ❄️ Аура Стужи (Frost Aura)
- **Стоимость**: 40 маны
- **Эффект**: создает вокруг игрока ледяную ауру, замедляющую врагов
- **Радиус**: 3 блока
- **Продолжительность**: 15 секунд

#### 🛡️ Поглощающий барьер (Absorbing Barrier)
- **Стоимость**: 15 маны
- **Эффект**: создает защитный барьер, поглощающий урон
- **Прочность**: 50 единиц урона

#### 💀 Проклятие Слабости (Weakness Curse)
- **Стоимость**: 45 маны
- **Эффект**: накладывает на врагов эффект слабости
- **Дебафф**: Слабость II на 8 секунд

#### 🧊 Стена льда (Ice Wall)
- **Стоимость**: 10 маны
- **Эффект**: создает ледяную стену, блокирующую проход
- **Размер**: 5x3 блока
- **Продолжительность**: 20 секунд

#### ⚔️ Накаливание (Heat Weapon)
- **Стоимость**: 25 маны
- **Эффект**: поджигает оружие в руках, увеличивая урон
- **Продолжительность**: 12 секунд

### 📚 Система изучения заклинаний

Manaborn использует прогрессивную систему изучения - игроки должны находить книги заклинаний и изучать их через Алтарь Изучения.

#### Книги заклинаний
- **Нахождение**: можно найти в сундуках по всему миру
- **Типы**: каждая книга содержит одно конкретное заклинание
- **Использование**: изучается через Алтарь Изучения (книга исчезает после изучения)
- **Подсказки**: в описании книги указано заклинание и стоимость маны

#### Алтарь Изучения (Learning Altar)
Мистический блок для изучения новых заклинаний.

**Крафт:**
```
  📚    (Книга заклинания)
 🪦     (Каменный кирпич)
🪦🪦🪦 (Каменный кирпич)
```

**Ингредиенты:**
- 5x Каменный кирпич (`minecraft:stone_bricks`)
- 1x Книга заклинания (любая)

**Использование:**
- **ПКМ** по алтарю с книгой заклинаний в руке
- Откроется интерфейс изучения
- Подтвердите изучение - книга исчезнет, заклинание будет добавлено

**Особенности:**
- Изученные заклинания сохраняются навсегда
- Можно изучить все 9 доступных заклинаний
- После изучения заклинание становится доступным в магическом посохе

```

│   │   ├── MagicStaffItem.java      # Магический посох
│   │   ├── SpellBookItem.java       # Книги заклинаний

│   │   ├── MagicDustItem.java       # Магическая пыль
│   │   └── ManaVesselItem.java      # Сосуды маны
│   ├── mana/                        # Система маны
│   │   └── ManaManager.java         # Управление маной

    ├── ManabornClient.java          # Клиентская инициализация
```

### Ключевые компоненты

#### ManaManager
- Управление маной игроков на сервере
- Автоматическая регенерация
- Синхронизация с клиентом через пакеты

#### SpellManager
- Обработка каста заклинаний
- Проверка стоимости маны и изученных заклинаний
- Переключение между изученными заклинаниями
- Делегирование в SpellRegistry для конкретных реализаций

#### SpellRegistry
- Централизованный реестр всех заклинаний
- Фабрика для создания экземпляров заклинаний
- Управление параметрами заклинаний (стоимость, кулдаун)

#### LearnedSpellsManager
- Управление изученными заклинаниями игроков
- Сохранение прогресса между сессиями
- Синхронизация с клиентом

#### IceShardEntity & FireWallEntity
- Кастомные сущности-снаряды
- Применение эффектов при попадании
- Наследуются от базовых классов Minecraft

#### HUD Overlays
- Используют современный API `HudElementRegistry` (1.21+)
- Визуальное отображение маны (пузырьки)
- Отображение активного заклинания и кулдаунов
- Адаптивное позиционирование на экране

#### Learning Altar
- Интерфейс для изучения новых заклинаний
- Валидация и обработка книг заклинаний
- Анимации и звуковые эффекты

### Сетевая синхронизация

Мод использует систему `CustomPayload` для синхронизации данных:

```java
// Синхронизация маны
public record ManaSyncS2CPacket(int mana, int maxMana) implements CustomPayload

// Синхронизация изученных заклинаний
public record LearnedSpellsSyncS2CPacket(Set<SpellType> learnedSpells) implements CustomPayload

// Запрос на синхронизацию изученных заклинаний
public record RequestLearnedSpellsC2SPacket() implements CustomPayload
```

Синхронизация происходит:
- При входе игрока на сервер
- После использования заклинания
- При регенерации маны
- После изучения нового заклинания
- При переключении заклинаний

## 🎮 Гайд для новичков

### Начало игры
1. **Создайте магический посох** - соберите 2 палки и 1 осколок аметиста
2. **Изучите базовые заклинания** - найдите книги заклинаний в сундуках
3. **Создайте Алтарь Изучения** - 5 каменных кирпичей + книга заклинаний
4. **Изучите заклинания** - используйте книги на алтаре

### Прогрессия
- **Ранний этап**: найдите Огненный шар и Ледяной осколок
- **Средний этап**: изучите защитные заклинания (Барьер, Стена льда)
- **Поздний этап**: освойте продвинутые заклинания (Стена огня, Проклятие слабости)

### Советы
- **Мана регенерируется** автоматически - подождите 2 секунды после использования
- **Ищите магическую руду** ниже Y=16 для крафта зелий
- **Сохраняйте книги заклинаний** - они исчезают после изучения
- **Используйте сосуды маны** для длительных походов

## 📦 Установка

### Для игроков

1. Установите [Fabric Loader](https://fabricmc.net/use/) версии 0.17.2 или выше
2. Установите [Fabric API](https://modrinth.com/mod/fabric-api) версии 0.134.1+1.21.10 или выше
3. Скачайте файл мода `manaborn-1.0.0.jar`
4. Поместите файл в папку `mods` вашего клиента/сервера Minecraft
5. Запустите игру с профилем Fabric

### Для разработчиков

#### Требования
- Java 21 или выше
- Minecraft 1.21.10
- Fabric Loader 0.17.2
- Fabric API 0.134.1+1.21.10

#### Настройка окружения

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Zottaks/Manaborn.git
cd Manaborn
```

2. Импортируйте проект в IDE (IntelliJ IDEA или Eclipse)

3. Выполните Gradle задачи для настройки:
```bash
./gradlew genSources
```

#### Запуск

```bash
# Запуск клиента
./gradlew runClient

# Запуск сервера
./gradlew runServer

# Сборка мода
./gradlew build
```

Собранный JAR файл будет находиться в `build/libs/`

## 🔧 Конфигурация

### Настройка маны

В файле `ManaManager.java`:

```java
public static final int MAX_MANA = 100;              // Максимальная мана
private static final int REGEN_UNIT_PER_5S = 20;     // Регенерация за 5 секунд
private static final int REGEN_DELAY_TICKS = 40;     // Задержка перед регеном (2 сек)
```

### Добавление новых заклинаний

1. Добавьте новый тип в `SpellType.java`:
```java
NEW_SPELL("Название", стоимость_маны, "id", Formatting.COLOR)
```

2. Реализуйте логику в `SpellManager.java`:
```java
case NEW_SPELL:
    castNewSpell(world, user);
    break;
```

3. Создайте метод каста:
```java
private static void castNewSpell(World world, PlayerEntity user) {
    // Ваша логика заклинания
}
```
