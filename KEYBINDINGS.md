# Настройка клавиш Manaborn

## Нативная система Minecraft

Клавиши для открытия меню заклинаний настраиваются **напрямую в игре** через стандартное меню настроек Minecraft!

## Две клавиши в категории Manaborn:

### 1. Open Spell Menu (+ Shift) - Открытие меню
- **По умолчанию:** `Z`
- **Функция:** Открывает меню выбора заклинаний
- **Требует:** Shift + настроенная клавиша
- Можно назначить любую клавишу или кнопку мыши

### 2. Toggle Menu Mode (Press/Hold) - Переключение режима
- **По умолчанию:** `Не назначено`
- **Функция:** Переключает режим работы меню между:
  - **Press (нажатие)** - нажал → меню остаётся открытым
  - **Hold (удержание)** - зажал → меню открыто, отпустил → закрылось
- Нажми эту клавишу, чтобы переключить режим
- При переключении покажется сообщение в action bar

## 🔒 ВАЖНО: Обе клавиши требуют Shift!

**БЕЗ зажатого Shift меню НЕ ОТКРОЕТСЯ!**

Это сделано для того, чтобы:
- Не конфликтовать с обычным использованием кнопок
- Не мешать ванильному геймплею
- Дать четкое разделение между обычными действиями и магией

## Как настроить:

1. Запустите Minecraft
2. Зайдите в **Options** → **Controls** → **Key Binds**
3. Прокрутите вниз до категории **"Manaborn"**
4. Найдите две клавиши:
   - **"Open Spell Menu (+ Shift)"** - для открытия меню (по умолчанию Z)
   - **"Toggle Menu Mode (Press/Hold)"** - для переключения режима (по умолчанию не назначено)
5. Нажмите на клавишу и назначьте свою кнопку

## Использование:

### Переключение режима:
1. Назначьте клавишу для **"Toggle Menu Mode"** (например, `M`)
2. В игре нажмите эту клавишу
3. В action bar (над хотбаром) появится сообщение:
   - `[Manaborn] Режим меню: Press (нажатие)` - или -
   - `[Manaborn] Режим меню: Hold (удержание)`

### Режим Press (нажатие) - по умолчанию:
1. Возьмите магический посох в руку
2. **ЗАЖМИТЕ Shift**
3. **НАЖМИТЕ** настроенную клавишу (Z по умолчанию)
4. Меню откроется и **останется открытым**
5. Выберите заклинание ЛКМ или закройте ПКМ/ESC

### Режим Hold (удержание):
1. Переключитесь в режим Hold (нажав клавишу переключения)
2. Возьмите магический посох в руку
3. **ЗАЖМИТЕ Shift + настроенную клавишу** (Z по умолчанию)
4. Меню откроется и **будет открыто, пока зажато**
5. Выберите заклинание ЛКМ (не отпуская клавиши)
6. **ОТПУСТИТЕ клавиши** → меню закроется

## Особенности:

- ✅ Работает как стандартный keybind Minecraft
- ✅ Можно назначить любую клавишу или кнопку мыши
- ✅ Показывается в разделе "Key Binds" игры
- ✅ Поддерживает конфликты клавиш (Minecraft покажет предупреждение)
- ✅ Сохраняется в настройках игры автоматически
- ✅ **Обязательно требует Shift** для активации

## Примечания:

- Меню открывается **только** когда в руке магический посох
- **Shift ОБЯЗАТЕЛЕН** - без него меню не откроется
- **Режим сохраняется** между запусками игры
- Переключение режима работает **всегда**, даже без посоха в руке
- **ЛКМ** - выбрать заклинание и закрыть
- **ПКМ** или **ESC** - закрыть без выбора (только в режиме Press)

## Примеры настроек:

### Вариант 1: Классический (для мыши)
```
Open Spell Menu: Правая кнопка мыши (ПКМ)
Toggle Menu Mode: M
Режим: Hold (удержание)
```
**Использование:** Зажал `Shift + ПКМ` → меню открыто → отпустил → закрылось

### Вариант 2: Современный (для клавиатуры)
```
Open Spell Menu: Z
Toggle Menu Mode: M  
Режим: Press (нажатие)
```
**Использование:** Нажал `Shift + Z` → меню открылось и остаётся

### Вариант 3: Удобный для боя
```
Open Spell Menu: Средняя кнопка мыши (СКМ)
Toggle Menu Mode: Не назначено (режим Press по умолчанию)
Режим: Press (нажатие)
```
**Использование:** Нажал `Shift + СКМ` → выбрал заклинание → закрыл ПКМ
