1. ✅ ДОБАВЛЕН МЕТОД tickBattleHymns()

Файл: BattleHymnSpell.java

public static void tickBattleHymns(Iterable<ServerPlayerEntity> players) {
    for (ServerPlayerEntity player : players) {
        UUID playerId = player.getUuid();
        if (activeChannels.containsKey(playerId)) {
            // Обновляем каст этого игрока
            if (!(player.getEntityWorld() instanceof ServerWorld world)) continue;
            
            BattleHymnSpell spell = new BattleHymnSpell();
            spell.updateChanneling(player, world);
        }
    }
}

Этот метод:
- Вызывается КАЖДЫЙ ТИК сервера
- Проверяет всех игроков с активными кастами
- Обновляет состояние каста (музыка, частицы, прогресс)

КАСТ ЗАКЛИНАНИЯ (1 раз):
cast() → startChanneling()
- Создаёт ChannelData
- Добавляет в activeChannels
- Накладывает дебаффы
- Проигрывает первую ноту

КАЖДЫЙ ТИК СЕРВЕРА (20 раз в секунду):
ServerTickEvents → tickBattleHymns()
- Для каждого игрока с активным кастом
- Вызывает updateChanneling()

updateChanneling() КАЖДЫЙ ТИК:
1. Проверяет движение (каждый тик)
2. Проигрывает ноту (каждые 20 тиков)
3. Показывает частицы (каждые 10 тиков)
4. Обновляет прогресс-бар (каждый тик)
5. Проверяет завершение (каждый тик)

ЗАВЕРШЕНИЕ (когда elapsed >= duration):
updateChanneling() → completeChanneling()
- Финальный аккорд
- Поиск игроков в радиусе
- Наложение баффов
- Частицы
- Удаление из activeChannels
