6. SpellManager.java - УПРАВЛЕНИЕ ЗАКЛИНАНИЯМИ
================================================================================

Путь: src/main/java/com/manaborn/spells/SpellManager.java

КАСТ:
    public static void castSpell(world, user, hand) {
        SpellType spell = getSelectedSpell(stack);
        
        if (!world.isClient()) {
            if (!ManaManager.tryConsume(player, spell.getManaCost())) {
                return;  // Недостаточно маны
            }
            
            switch (spell) {
                case FIREBALL:
                    castFireball(world, user);
                    break;
                case ICE_SHARD:
                    castIceShard(world, user);
                    break;
            }
        }
        
        user.getItemCooldownManager().set(stack, 100);  // 5 сек
    }

ХРАНЕНИЕ ВЫБРАННОГО ЗАКЛИНАНИЯ:
    public static SpellType getSelectedSpell(ItemStack stack) {
        NbtComponent customData = stack.get(CUSTOM_DATA);
        if (customData == null) {
            return SpellType.FIREBALL;
        }
        String spellId = nbt.getString(KEY).orElse("fireball");
        return SpellType.fromId(spellId);
    }

NBT = данные в предмете
Сохраняются при перезаходе

СМЕНА ЗАКЛИНАНИЯ:
    public static void cycleSpell(ItemStack stack) {
        SpellType current = getSelectedSpell(stack);
        SpellType[] spells = SpellType.values();
        int nextIndex = (current.ordinal() + 1) % spells.length;
        setSelectedSpell(stack, spells[nextIndex]);
    }

    public enum SpellType {
        FIREBALL("Огненный шар", 20, "fireball"),
        ICE_SHARD("Ледяной осколок", 35, "ice_shard");
        
        private final String displayName;
        private final int manaCost;
        private final String id;
        
        public String getDisplayName() { return displayName; }
        public int getManaCost() { return manaCost; }
        public String getId() { return id; }

8. IceShardEntity.java - ЛЕДЯНОЙ СНАРЯД

    public class IceShardEntity extends ArrowEntity {
        public IceShardEntity(World world, LivingEntity owner) {
            super(ManabornMod.ICE_SHARD_ENTITY, world);
            this.setOwner(owner);
            this.setPosition(owner.getX(), owner.getEyeY(), owner.getZ());
        }
        
        @Override
        protected void onEntityHit(EntityHitResult hit) {
            if (hit.getEntity() instanceof LivingEntity target) {
                // Замедление 5 сек, уровень 2
                target.addStatusEffect(
                    new StatusEffectInstance(SLOWNESS, 100, 2), 
                    this.getOwner()
                );
                this.playSound(SNOWBALL_THROW, 1.0f, 1.2f);
            }
            this.discard();
        }
    }

extends ArrowEntity = наследуем поведение стрелы

9. FIREBALL vs ICE SHARD
================================================================================

FIREBALL:
    private static void castFireball(World world, PlayerEntity user) {
        SmallFireballEntity fireball = new SmallFireballEntity(
            world, user, user.getRotationVector()
        );
        fireball.setPos(user.getX(), user.getEyeY(), user.getZ());
        world.spawnEntity(fireball);
        world.playSound(..., FIRECHARGE_USE, ...);
    }

- Стоимость: 20 маны
- Ванильная сущность
- Поджигает

ICE SHARD:
    private static void castIceShard(World world, PlayerEntity user) {
        IceShardEntity iceShard = new IceShardEntity(world, user);
        iceShard.setVelocity(user, pitch, yaw, 0, 2.0f, 1.0f);
        world.spawnEntity(iceShard);
        world.playSound(..., SNOWBALL_THROW, ...);
    }

- Стоимость: 35 маны
- Кастомная сущность
- Замедляет
